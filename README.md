# Сметчик металла

Калькулятор металлоконструкций для цеха: считает металл, себестоимость и цену изделия.

**Рабочая версия:** https://claude.ai/artifact/MGtYoYx9xsSDQwt1KrJCWs (данные в облаке, распознавание по фото)

## Что умеет

- **Шаблоны изделий** — конструкция описывается один раз: детали и формулы длины от размеров (`2*W+2*H`, `ceil(L/0,8)+1`). Дальше вводятся только размеры.
- **Прайсы поставщиков** — каждый прайс хранится целиком (`data/`, коллекция `pricelists`): Траст-Караганда (чёрный металл, 02.10.2026, 95 поз.) и IMEX Trade (нержавейка, 05.10.2026, 150 поз.). Свои правки цен поверх прайса действуют до прихода более свежего прайса этого поставщика. Сборка: `node tools/build-pricelists.js data`.
- **Металл по целым хлыстам** — поставщик продаёт прокат целыми хлыстами, поэтому металл считается по карте реза (купленные хлысты × цена), остаток хлыста — это отход.
- **Каталог металла** — вес погонного метра считается по размерам сечения (ГОСТ 30245 с учётом скруглений, круглая труба, уголок, лист, арматура). Цена за кг или за единицу. Массовое изменение цен на %.
- **Себестоимость** — металл, отходы (только на режущийся прокат), расходники, покраска, работа за кг + часы, монтаж, бензин по км и расходу, выезды, постоянные расходы (аренда и т.п.), распределённые на кг, наценка, скидка, округление.
- **По фото или описанию** — Claude распознаёт изделие, подбирает шаблон или собирает детали из вашего каталога.
- **Заказы** — история, статусы, статистика за месяц (конверсия, тоннаж, выручка, средняя цена за кг), «как новый» — пересчёт старого заказа по текущим ценам.
- **Карта реза** — детали (шт × длина) раскладываются по хлыстам методом best-fit с учётом ширины реза; длинные детали стыкуются. Текст для мастера копируется одной кнопкой.
- **Что закупить** — сводка металла по заказу; число хлыстов берётся из карты реза.
- **Коммерческое предложение** — PDF с логотипом и реквизитами, цена по позициям, условия оплаты, срок, гарантия. Плюс текст для WhatsApp и смета в CSV.
- **Деньги** — фото чеков и PDF-выписка Kaspi распознаются в операции по статьям, оплаты привязываются к заказам. Месячная сводка по статьям.
- **План против факта** — по каждому заказу: смета против реальных расходов, оплачено, долг клиента, прибыль после сдачи.
- **Налог** — ИПН для ИП на ОУР: доход минус расходы с документами (чек, накладная, ЭСФ), ставка и дата начала учёта настраиваются, доначисления по уведомлениям, подсказка «сколько сэкономит найденный чек», контроль порога НДС.
- **Коэффициенты по факту** — расходники, краска, работа на 1 кг и постоянные расходы пересчитываются по реальным тратам за 1–12 месяцев.

## Структура

- `calc.js` — расчёты, без DOM (работает в браузере и Node)
- `app.js` — интерфейс и хранилище (облачная база артефакта либо localStorage)
- `index.html` — разметка и стили
- `tests/calc.test.js` — тесты: `npm test`

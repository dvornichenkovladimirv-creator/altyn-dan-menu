# Time Tracker

Приложение учёта рабочего времени: React + TypeScript + Vite + Tailwind CSS.

## Возможности

- Старт/стоп таймера по проекту с живым отсчётом времени
- Управление проектами (добавление/удаление, цветовая метка)
- Ручное добавление и редактирование записей (описание, проект, время начала/конца)
- Сводка: сегодня / за неделю, разбивка по проектам
- Все данные хранятся локально в браузере (localStorage)
- Устанавливается как приложение на телефон (PWA): манифест, иконки, офлайн-кеш через service worker

## Разработка

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Установка на телефон

Установка PWA (кнопка «Добавить на экран» / автоустановка) требует HTTPS —
по обычной локальной сети браузеры её не предлагают.

**Автодеплой на GitHub Pages** уже настроен (`.github/workflows/deploy.yml`):
при каждом пуше в `main` сайт собирается и публикуется автоматически. Чтобы
включить это один раз: **Settings → Pages → Build and deployment → Source:
GitHub Actions**. После этого приложение будет доступно по адресу
`https://<владелец>.github.io/altyn-dan-menu/`.

Дальше на телефоне:
- **Android (Chrome):** открыть ссылку → меню (⋮) → «Установить приложение».
- **iPhone (Safari):** открыть ссылку → кнопка «Поделиться» → «На экран «Домой»».

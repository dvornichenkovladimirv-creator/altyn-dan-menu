# altyn-dan-menu
## Креативы

- `content/<NN-тема>/` — готовые PNG для Instagram (1080×1350) и WhatsApp-статусов (1080×1920) + подпись к посту.
- `tools/creatives/gen_photos.py <папка>` — генерирует фото через OpenAI (gpt-image-2) по промптам из `<папка>/photos.json`.
- `tools/creatives/render_loft.py` — собирает слайды «Лофт-стол» поверх фото (шрифт Montserrat в `tools/creatives/fonts`).

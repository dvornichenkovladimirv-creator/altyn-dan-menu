# altyn-dan-menu

## Бюджет — приложение доходов и расходов (`docs/`)

Мобильное веб-приложение (PWA): ставится на главный экран телефона и работает офлайн.

- **Постоянные** доходы/расходы (зарплата, аренда, кредиты, подписки) — ежемесячно, еженедельно или раз в год, с отметкой «оплачено».
- **Переменные** траты и доходы по категориям, лимиты на категории.
- **Прогноз**: остаток на конец месяца, «можно тратить в день», доходы/расходы и баланс на 6 месяцев вперёд (по среднему за последние 3 месяца).
- Резервная копия (JSON) и выгрузка в CSV для Excel.

Данные хранятся только на устройстве (localStorage).

### Запуск
GitHub → Settings → Pages → Branch: `main`, папка `/docs`. Затем открыть ссылку на телефоне и «Добавить на главный экран».
Локально: `cd docs && python3 -m http.server`.

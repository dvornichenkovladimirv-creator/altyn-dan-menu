# altyn-dan-menu

## warehouse (склад-учёт)

Отдельное приложение для учёта склада ресторана/кафе: приход, списание,
перемещение между складами, инвентаризация, остатки и журнал движений.
Логика похожа на сервисы класса "Контролата" — независимая реализация,
без использования чужого кода или брендинга.

Стек: Express + TypeScript + Prisma (SQLite) на бэкенде,
React + Vite + TypeScript + Tailwind на фронтенде.

### Запуск

```bash
# Сервер
cd server
npm install
cp .env.example .env
npm run prisma:migrate
npm run seed      # создаёт admin@warehouse.local / admin123 и демо-данные
npm run dev        # http://localhost:4000

# Клиент (в отдельном терминале)
cd client
npm install
npm run dev        # http://localhost:5173
```

### Возможности

- Авторизация (JWT), роли admin/manager/storekeeper
- Справочники: единицы измерения, склады, поставщики, номенклатура
- Документы движения:
  - **Приёмка** — поступление от поставщика, расчёт средней себестоимости
  - **Списание** — расход со склада с проверкой достаточности остатка
  - **Перемещение** — между складами
  - **Инвентаризация** — сверка фактического остатка с учётным
- Отчёты: остатки по складам со стоимостью, журнал движений с фильтрами

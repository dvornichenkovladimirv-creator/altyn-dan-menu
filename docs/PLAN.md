# Бюджет: структура и план разработки

Статус: план утверждён по ключевым решениям (раздел 2). Прототип (v0) в `docs/` — кликабельный макет, чтобы проверить структуру на реальном телефоне. Окончательные решения — в разделе 2.

## 1. Цель

Одно приложение на телефоне, где за 10 секунд записываешь трату и в любой момент видишь:
- сколько можно тратить сегодня, чтобы хватило на обязательные платежи;
- сколько останется в конце месяца;
- что будет с деньгами через 3–6 месяцев при текущих привычках.

Критерий успеха: пользуюсь каждый день 2 месяца подряд, прогноз конца месяца ошибается не больше чем на 10%.

## 2. Принятые решения

| # | Вопрос | Решение | Следствие |
|---|--------|---------|-----------|
| 1 | Кто пользуется | только я | без входа и регистрации, без общего доступа |
| 2 | Где данные | только телефон | нет сервера и затрат; **риск потери** закрываем напоминанием о резервной копии и копией в один тап (Файлы / Google Drive / Telegram) |
| 3 | Как вносить траты | вручную, импорт выписки позже | на старте главное — быстрый ввод в 3 касания |
| 4 | Счета | один общий баланс | без счетов и переводов; раз в месяц — «сверить баланс с фактическим» |
| 5 | Платформа | PWA (веб-приложение на главном экране) | бесплатно, iOS и Android, работает офлайн |

## 3. Структура данных

```
Бюджет (на телефоне)
 ├─ Категории         — название, тип (доход/расход), лимит в месяц
 ├─ Постоянные        — шаблон: тип, название, сумма, категория,
 │                      периодичность (месяц/неделя/год), день, с/по даты
 ├─ Операции          — дата, сумма, тип (доход/расход), категория,
 │                      комментарий, ссылка на постоянный (если из шаблона)
 ├─ Цели накоплений   — название, сумма, срок, сколько отложено
 └─ Настройки         — валюта, начальный остаток, неснижаемый остаток,
                        день начала месяца (день зарплаты), дата последней копии
```

Ключевые правила:
- **Постоянный** — это шаблон (план). **Операция** — факт. Отметка «оплачено» создаёт операцию из шаблона; сумму можно поправить (коммуналка каждый месяц разная).
- **Переменные** траты — все операции без ссылки на шаблон.
- Сумма постоянного может меняться: хранить историю изменений, чтобы прошлые месяцы не пересчитывались.
- Расхождение с реальным балансом исправляется операцией «корректировка», а не правкой начального остатка — чтобы было видно, сколько «потерялось».

## 4. Структура экранов

```
Нижнее меню
├─ Обзор         баланс · «можно тратить в день» · остаток на конец месяца ·
│                траты по категориям vs лимиты · ближайшие платежи
├─ Операции      список по дням · фильтр доход/расход/категория · поиск
├─ Постоянные    план месяца с галочками «оплачено» · просроченные · шаблоны
├─ Прогноз       этот месяц · 6 месяцев (график + таблица) · «что если»
└─ Ещё           категории и лимиты · цели · резервная копия · настройки
Кнопка «+»       быстрый ввод: сумма → категория → готово (≤ 3 касаний)
```

## 5. Логика прогноза

1. **Остаток на конец месяца** = баланс сейчас + неполученные постоянные доходы − неоплаченные постоянные расходы − ожидаемые переменные траты до конца месяца.
2. **Ожидаемые переменные траты** = среднее в день за последние 3 месяца, смешанное с темпом текущего месяца. Без истории — только темп текущего месяца.
3. **Можно тратить в день** = (баланс + ожидаемые доходы − обязательные платежи − подушка) / оставшиеся дни.
4. **6 месяцев вперёд**: постоянные по шаблонам (с учётом дат окончания кредитов) + переменные по среднему. Предупреждение, если баланс уходит в минус.
5. **«Что если»** (этап 2): «если сокращу кафе на 20%», «если возьму кредит 30 000/мес» — и сразу видно, как меняется прогноз.

## 6. Этапы

| Этап | Что входит | Результат | Срок* |
|------|-----------|-----------|-------|
| 0. Прототип ✅ | экраны, постоянные/переменные, прогноз, локальное хранение | можно потрогать на телефоне | готово |
| 1. MVP | месяц от дня зарплаты, правка суммы при отметке «оплачено», быстрый ввод (≤ 3 касаний), корректировка баланса, история сумм постоянных, публикация по ссылке | ежедневное использование | 1–2 дня |
| 2. Надёжность | напоминание о резервной копии раз в неделю, копия в один тап, восстановление, проверка на iPhone и Android | данные не теряются | 0,5–1 день |
| 3. Прогноз+ | «что если», цели накоплений, сравнение месяцев, поиск по операциям | планирование, а не только учёт | 1–2 дня |
| 4. Импорт | импорт выписки банка (CSV/PDF), автокатегории по прошлым операциям, защита от дублей | ручной ввод почти не нужен | 2–3 дня |

\* время работы, не календарное; после каждого этапа — проверка на телефоне и ваше «ок».

## 7. Риски

- **Забрасывание ввода** — главный риск любого бюджета. Ответ: быстрый ввод, импорт выписки, ежедневное напоминание.
- **Потеря данных** при хранении только на телефоне (смена телефона, очистка браузера, на iPhone Safari может удалить данные неиспользуемого сайта через 7 дней — у установленного на главный экран приложения этого ограничения нет). Ответ: установка на главный экран обязательна + еженедельная копия (этап 2). Если риск станет неприемлемым — облако добавляется без переделки структуры.
- **Неточный прогноз в первый месяц** — честно показывать «мало данных».
